Existing subscriptions

Your subscriptions.
One terminal.

Something like Claude Code, but for more than one plan. Kolkrabbi signs into Claude Pro or Max, ChatGPT Plus or Pro (the Codex plans) and GitHub Copilot through each vendor's own CLI, and lets one session move between them. No API key, no metered bill for what your plans already cover, and when one plan hits its limit the work does not stop.

Verified 6 September 2026 on Claude Max, ChatGPT Plus and Copilot Free. Also in Spanish: agente de código para varias suscripciones.

Kolk never reads a vendor's credential, token or cookie. It starts the CLI you already logged into and records what comes back. Each plan's own limits apply exactly as the vendor set them.

When a plan runs out

The limit is the vendor's. The stop is not.

A subscription allowance, an account quota and a capacity limit are told apart, and each is remembered across your sessions. By default kolk pauses, keeps your turn, and resumes by itself when the limit lifts — spending nothing to wait. It also tells you what could carry on: the best equivalent model on another plan you have, the same rung of the ladder, and the command that switches to it.

  • /continue walks that chain when you say so.
  • /config set continuity.mode on walks it by itself, subscriptions first, then paid keys, then a free model only if you listed one.
  • /config set continuity.select ask asks once per run instead.

Two minutes

Sign in, then pick a plan per model.

curl -fsSL https://kolkrabbi.francomichetti.com/install.sh | sh
kolk
/plans login anthropic "Claude Max"
/plans login openai "ChatGPT Plus"
/plans login github "Copilot Free"
/model "ChatGPT Plus/gpt-5.6-sol"

Each login opens the vendor's own sign-in and comes back. /plans shows which are signed in and verified; /model lists every model every plan offers, with the plan it belongs to.

What this is not.

It is not a way around a plan's limits: kolk never proxies one account for several people, never bypasses a quota, and never scrapes a browser session. It is not the only open-source agent that connects a subscription — OpenCode does too, through its own connectors. What kolk adds is the continuity across plans described above, a local record of what each model cost and how you rated it, and one static binary that starts in milliseconds.
