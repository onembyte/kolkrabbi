The gateway

Every model,
one key.

OpenRouter is the door to most of the catalogue — GPT, Gemini, DeepSeek, Qwen, Kimi and the rest — behind a single key. Kolkrabbi treats it as the default route, and starts on a model that costs nothing before you have decided anything.

Commands checked against kolk help on 2026-09-04.

01 / FREE FIRST

It starts free, without being asked.

The zero-config path is a real one, not a trial.

HowDISCOVERY

It asks the live catalogue

For a new session with no model chosen, Kolkrabbi asks OpenRouter's live catalogue for zero-cost, tool-capable models and prefers the strongest coding-oriented one. If the catalogue is unreachable, it falls back to OpenRouter's guaranteed zero-cost openrouter/free router.

HowOVERRIDE

Your choice always wins

A saved model, -m, or a custom effort-tier map beats discovery every time, because those are explicit decisions and discovery is a guess.

HowKEY

One key, one destination

/key stores it. It only ever goes to openrouter.ai — never to a local endpoint, never to a --base-url you pass.

02 / THE DIAL

The effort dial picks the model.

This is the part that is unlike other agents. Elsewhere, effort means how many thinking tokens one model spends. Here it decides which model runs the turn, and how wide the agent work goes.

Set with /effort in a session, or -e on the way in.
EffortWhat it selects
lowA cheap, fast model. Routine edits, renames, questions about the codebase.
mediumA balanced model. The default working tier.
highA strong reasoning model, for work that has bitten you before.
maxA frontier model, and wider agent orchestration.

03 / THE LEDGER

Then it tells you what that cost.

Every call is appended to a JSONL file you own. Nothing is uploaded, and there is no account to log into.

LocalSTATS

Cost, latency, tokens, ratings

/stats aggregates per model: how many calls, how many tokens, what it cost, how long it took, and the 1–5 ratings you gave with /rate. /dash serves the same numbers as a loopback-only page.

LocalMOMENT

And in the moment

The status line carries mode, model, effort, context use and what the session has cost so far, so the number is in front of you while you decide, not afterwards.

LocalMIXED

Across every route at once

Gateway turns, local turns and subscription turns land in the same file. Subscription turns are labelled API-equiv. and never pooled with metered spend — a Max subscriber's marginal cost is zero, and a number that pretends otherwise is worse than no number.
