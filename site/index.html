Kolkrabbi is an open-source AI coding agent for the terminal — a Claude Code and Codex CLI alternative. Chat, code, and agent work across several subscriptions in one session — your Claude Pro or Max, your ChatGPT Plus or Pro, your GitHub Copilot — any OpenRouter model, or a local model on Ollama. One static binary under 9 MB, milliseconds to start, computed defaults, and your sessions kept on your machine.

01 / START

No setup ceremony.

Install. Run. Add one key when Kolkrabbi asks for it.

~/terminal Installer ships with v1.3.1
  1. Install
    $ curl -fsSL https://kolkrabbi.francomichetti.com/install.sh | bash
  2. Run $ kolk kolk needs an API key before it can use models.
    Add one:  /key <API_KEY>
    Then run: kolk     ❯ /key <API_KEY>
  3. Use it $ kolk
  4. Remove it $ kolk uninstall Lists every file it will delete, with what each one holds, and asks once.
    Keep your key and sessions for later:  kolk uninstall --keep-data

Verified release. The installer accepts only published Kolkrabbi release assets and verifies their checksum before installing.

Prefer Homebrew? brew install onembyte/tap/kolk — macOS and Linux, and the formula is generated from the release’s own signed checksums, so brew verifies the same bytes. To type the short name instead, trust the tap once with brew tap onembyte/tap && brew trust onembyte/tap, then brew install kolkrabbi.

03 / THE POINT

Complexity, shipped off.

[ A ]

Any model

Start with a computed default. Choose another model only when you actually care.

[ L ]

Local memory

Sessions, checkpoints, ratings, and cost history stay local and inspectable.

[ 3 ]

Three modes

Chat for thinking, code for focused building, agent for longer work with an ordered plan, isolated subagents, and one final synthesis.

[ $ ]

Spend where it counts

In agent mode each planned task is routed: the trivial ones to the cheapest rung your plan offers, the rest to your model, and a slot per role can pin a cheaper model to a kind of work. Your local dashboard shows what share of tokens ran below your top rung.

04 / OPINIONATED

The interface should disappear.

  • 01 Zero-config is the product.

  • 04 Simple to type beats simple to explain.

05 / PROVIDERS

Every provider on the map.

Lit means Kolkrabbi can reach it today. Dimmed says where the rest stand, in the words of the record: chosen, with a keyed client no live key has proven; investigating, until the access path is settled; or deferred past v1 — listed, never promised.

  • OpenRouter The gateway — every model it lists Works today
  • Anthropic Claude Free · Pro · Max, via the claude CLI Works today
  • Ollama Your own Ollama, found and used — local models and Ollama Cloud behind its sign-in Works today
  • LiteLLM Proxy over an OpenAI-compatible URL Works today
  • vLLM Self-hosted over an OpenAI-compatible URL Works today
  • OpenAI ChatGPT Plus · Pro, via the Codex CLI Works today
  • Google Gemini API key, metered · Gemini Free, AI Pro and AI Ultra are not API access Chosen · key, unproven
  • xAI Grok, by API key, metered Chosen · key, unproven
  • Perplexity By API key once the endpoint is settled Investigating
  • Mistral Le Chat, by API key Deferred past v1
  • DeepSeek DeepSeek, by API key Deferred past v1
  • Qwen Qwen / Model Studio, by API key Deferred past v1
  • Cohere Cohere, by API key Deferred past v1
  • GitHub Copilot Free · Pro · Pro+ · Business · Enterprise, via the copilot CLI Works today

Dimmed is about the direct path — a first-party CLI handover or a native key of your own. Most of those models are already usable through the gateway tile above, which is the one doing the work today.
