01 / START

No setup ceremony.

Install. Run. Add one key when Kolkrabbi asks for it.

~/terminal Installer ships with v0.1
  1. Install $ curl -fsSL https://kolkrabbi.francomichetti.com/install.sh | bash
  2. Run $ kolk kolk needs an API key before it can use models.
    Add one:  kolk key <API_KEY>
    Then run: kolk
  3. Use it $ kolk key <API_KEY>
    $ kolk

Early build. The page is ready for review; the public installer turns on only after signed release artifacts and checksums pass the clean-machine rehearsal.

02 / THE POINT

Complexity, shipped off.

[ A ]

Any model

Start with a computed default. Choose another model only when you actually care.

[ L ]

Local memory

Sessions, checkpoints, ratings, and cost history stay local and inspectable.

[ 2 ]

Two modes

Chat for thinking, code for building. Same terminal, same history.
